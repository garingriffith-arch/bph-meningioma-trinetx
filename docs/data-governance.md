# Data governance

The analytic input is a licensed TriNetX electronic health record extract. Do not commit or distribute raw source tables, the DuckDB database, person-level exports, credentials, derived identifiable records, or locally generated unreviewed outputs. The RFD non-human-subjects determination (STUDY00030063; April 7, 2026) does not itself authorize redistribution of third-party data or code.

Repository visibility must remain **private** until institutional and contractual code-sharing rules have been checked. Grant reviewers access only as authorized. Even aggregate files can be governed by cell-size thresholds or disclosure policies; review them before release. No general reuse license is granted.
