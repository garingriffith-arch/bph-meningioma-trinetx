# Data governance and disclosure

The analyses use an institutionally accessed TriNetX electronic health record extract. Raw source tables, the working DuckDB database, person-level records, credentials, derived identifiable records, and restricted analysis outputs are not part of this repository.

Only source code and methodological documentation are provided. Aggregate statistics may also be subject to institutional minimum-cell and disclosure requirements and should be reviewed before release.

The institutional non-human-subjects research determination addresses human-subjects oversight; it does not independently authorize third-party data redistribution or establish rights to publish or license code. The public status of this repository should not be interpreted as confirmation of permissions beyond the materials actually posted.

Researchers with authorized data access should work in a separate local directory and must not commit exported data or intermediate results. No open-source license is granted by this repository.
